# bili-clip

从长视频里切出来的竖屏，不是“最精彩那段”的剪辑，而是**脱离原视频也能成立**的一段——这个集合小得多。

工具是这个仓库的 `bili` 命令（Go 写的，零依赖，只读本地文件，不登录、不调 B站接口）。没装的话：

```bash
go install github.com/venciallee/bilibili-agent-skill/cmd/bili@latest
```

装不了 Go 时，按下面的规则手工检查，并在输出里写明“这次没有跑工具”。

## 挑选

读字幕，找 20 到 60 秒、同时满足三条的段落：

1. 开在一个完整的意思上。第一句需要前一分钟的铺垫才听得懂，就不是切片。
2. 中间有一个转折：一个说法，然后有东西让它变复杂或者证明它。
3. 结在一句话上，不是说着说着没了。

有弹幕就先跑 `bili danmaku`：笑和高能的高峰是候选，但候选还要过上面三条。

把前五个候选连同时间码和第一句话给用户看，让他不用读完整份字幕就能否掉一个。

## 写每一条

- **新的第一句。** 原视频里的那句话默认观众有上下文，这个观众没有。写一句替换的，过一遍 `bili hook`。
- **前两秒的屏幕大字**，和说出来的那句用不同的字。
- **循环点**：最后一句要能接回第一句。
- **竖屏构图**：16:9 裁成 9:16 会丢掉什么，丢掉要不要紧——字幕、屏幕录制、两个人的对话最容易出事。

## 边界

只切用户自己的视频，或者已经拿到授权的内容。别人的视频和直播，先有授权再切。

## 闸门

这里什么都不会发布。skill 只负责写，投稿由你来点。每次输出都以一个可以直接复制的块结尾，最后一句永远是：**就这么发，还是改？**
